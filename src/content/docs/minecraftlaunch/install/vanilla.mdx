该安装器用于安装原版 Minecraft，支持所有正式发布的版本。

### 获取版本信息

```csharp
using MinecraftLaunch.Components.Installer;

var minecrafts = VanillaInstaller.EnumerableMinecraftAsync();

// 获取指定的 Minecraft 版本
var minecraft = minecrafts.First(x => x.McVersion == "1.21.1");

// 获取最新版本
var latest = minecraft.First();
```

<br></br>

### 初始化安装器

创建一个原版游戏安装器实例。

`entry` 参数类型为 `EnumerableMinecraftAsync` 获取到的安装版本实例

```csharp [CSharp]
var installer = VanillaInstaller.Create(".minecraft", minecraft);

```

<br></br>

### 开始安装

在完成初始化后，只需要调用 `InstallAsync` 方法来进行安装

```csharp [CSharp]
var minecraft = await installer.InstallAsync();

```

<br></br>

### 进度监控

您可以通过 `ProgressChanged` 事件获取当前的安装进度，事件参数包含以下信息：

| 属性名 | 描述 |
|--------|------|
| `Speed` | 当前下载速度，仅在 `IsStepSupportSpeed` 为 `true` 时更新值 |
| `Progress` | 当前总体进度 |
| `TotalStepTaskCount` | 当前步骤所有任务数 |
| `FinishedStepTaskCount` | 已完成的步骤任务数 |
| `Status` | 任务进度状态 |
| `StepName` | 步骤名字 |
| `IsStepSupportSpeed` | 当前步骤是否支持进度显示 |
